# STF Email Bot

An AI bot that auto-answers repeated **Student Travel Fund (STF)** emails sent to TESC (`contact@tescatucsd.org`, plus `board@`), 24/7, for about $0.50/month.

- **Plan:** [docs/PLAN.md](docs/PLAN.md)
- **How it works (diagram):** [docs/stf-bot-flow.png](docs/stf-bot-flow.png) (editable: `docs/stf-bot-flow.excalidraw`, open at excalidraw.com)

Bot code lives on the `prototype` branch until it's tested.
